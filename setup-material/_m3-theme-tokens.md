# M3 Theme Tokens Reference

## System-Level Color Tokens (`--mat-sys-*`)

These tokens are auto-generated by `@include mat.theme(...)` and resolve differently for light/dark themes.

### Surface & Background
| Token | Dark Theme Default | Usage |
|-------|--------------------|-------|
| `--mat-sys-surface` | `#121212` | Page background |
| `--mat-sys-on-surface` | `#e0e0e0` | Primary text on surface |
| `--mat-sys-surface-container` | `#1e1e1e` | Card/container background |
| `--mat-sys-surface-container-low` | `#191919` | Subtle container bg |
| `--mat-sys-surface-container-high` | `#242424` | Elevated container bg |
| `--mat-sys-surface-container-highest` | `#2b2b2b` | Highest elevation container |
| `--mat-sys-surface-dim` | `#141414` | Dimmed surface |
| `--mat-sys-surface-bright` | `#3b3b3b` | Bright surface |
| `--mat-sys-on-surface-variant` | `#c4c4c4` | Secondary text on surface |
| `--mat-sys-outline` | `#8e8e8e` | Borders, dividers |
| `--mat-sys-outline-variant` | `#4a4a4a` | Subtle borders |

### Primary / Accent
| Token | Dark Theme Default | Usage |
|-------|--------------------|-------|
| `--mat-sys-primary` | Accent color (e.g. azure) | Primary brand, links |
| `--mat-sys-on-primary` | `#fff` | Text on primary bg |
| `--mat-sys-primary-container` | Dark accent bg | Primary container bg |
| `--mat-sys-on-primary-container` | Light accent text | Text on primary container |

### Error / Danger
| Token | Dark Theme Default | Usage |
|-------|--------------------|-------|
| `--mat-sys-error` | `#f2b8b5` | Error/danger text |
| `--mat-sys-on-error` | `#601410` | Text on error bg |
| `--mat-sys-error-container` | `#8c1d18` | Error container bg |

### Success (custom, map from tertiary)
| Token | Usage |
|-------|-------|
| `--mat-sys-tertiary` | Can serve as success/positive color |

### Typography Tokens
| Token | Usage |
|-------|-------|
| `--mat-sys-body-large` | Default body text |
| `--mat-sys-body-medium` | Standard body |
| `--mat-sys-body-small` | Caption/helper text |
| `--mat-sys-label-large` | Button labels |
| `--mat-sys-label-medium` | Chip/tab labels |
| `--mat-sys-label-small` | Badge/overline labels |
| `--mat-sys-title-medium` | Card titles |
| `--mat-sys-headline-small` | Page titles |

### Elevation / Shape
| Token | Usage |
|-------|-------|
| `--mat-sys-level0` | No elevation shadow |
| `--mat-sys-level1` | Card shadow |
| `--mat-sys-level2` | Elevated card/dialog shadow |
| `--mat-sys-level3` | Menu/dropdown shadow |
| `--mat-sys-corner-extra-small` | 4px radius |
| `--mat-sys-corner-small` | 8px radius |
| `--mat-sys-corner-medium` | 12px radius |
| `--mat-sys-corner-large` | 16px radius |
| `--mat-sys-corner-full` | Full (pill) radius |

## Hex Color to M3 Token Migration Map

Use this table to replace hardcoded hex values with M3 system tokens:

| Hex Value | Current Usage | M3 Token Replacement |
|-----------|---------------|----------------------|
| `#0d0d0d` | Page bg (deepest) | `var(--mat-sys-surface)` |
| `#111` | Left panel bg | `var(--mat-sys-surface-dim)` |
| `#121212` | Dialog bg | `var(--mat-sys-surface)` |
| `#1a1a1a` | Card/table bg | `var(--mat-sys-surface-container)` |
| `#1e1e1e` | Panel header bg | `var(--mat-sys-surface-container-high)` |
| `#222` | Hover bg | `var(--mat-sys-surface-container-high)` |
| `#2a2a2a` | Border/divider | `var(--mat-sys-outline-variant)` |
| `#333` | Button bg | `var(--mat-sys-surface-container-highest)` |
| `#3a3a3a` | Border subtle | `var(--mat-sys-outline-variant)` |
| `#555` | Scrollbar/disabled | `var(--mat-sys-outline)` |
| `#888` | Secondary text | `var(--mat-sys-on-surface-variant)` |
| `#b0b0b0` | Body text | `var(--mat-sys-on-surface)` |
| `#ccc` | Light text | `var(--mat-sys-on-surface)` |
| `#e0e0e0` | Menu/dialog text | `var(--mat-sys-on-surface)` |
| `#fff` | Primary text | `var(--mat-sys-on-surface)` |
| `#4fc3f7` | Accent/highlight | `var(--mat-sys-primary)` |
| `#4caf50` | Success | `var(--mat-sys-tertiary)` |
| `#ff5252` | Error/danger | `var(--mat-sys-error)` |
| `#ff9800` | Warning/slow | `var(--mat-sys-secondary)` |

> **Note**: Exact token resolution depends on the palette chosen in `mat.theme()`. The table above maps conceptual equivalents. After migration, verify visual parity in the browser.
