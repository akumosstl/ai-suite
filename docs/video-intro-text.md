# AI Suite - Apresentação do Projeto

## Introdução

Bem-vindo ao AI Suite! Neste vídeo, vou apresentar um sistema poderoso de execução de pipelines de IA que permite criar, gerenciar e executar fluxos de trabalho automatizados com agentes de IA.

## O que é o AI Suite?

AI Suite é um **sistema híbrido de execução de pipelines** que combina:

- **Criação de Agentes de IA** - Build intelligent agents with custom prompts
- **Definição de Pipelines** - Orchestrate sequences de passos
- **Execução em Tempo Real** - Monitor progress with live updates
- **Suporte a Múltiplos Tipos** - Agents, scripts, skills, commands, plugins e tools

## Principais Funcionalidades

| Funcionalidade | Descrição |
|--------------|------------|
| Execução em Tempo Real | Server-Sent Events (SSE) para progresso ao vivo |
| Fallback com Polling | Atualizações confiáveis mesmo sem SSE |
| Tipos Rica de Entidades | Suporte a agents, skills, commands, scripts, plugins, tools e instructions |
| Organização por Namespace | Agrupe entidades por categoria |
| Sistema de Templates | Quick-start com padrões reutilizáveis |
| Configuração de Targets | Defina caminhos de recursos para diferentes ambientes |

## Para Quem é Indicado?

- Desenvolvedores que querem automatizar fluxos de trabalho com IA
- Equipes que precisam orquestrar múltiplas tarefas de IA em sequência
- Projetos que exigem monitoramento em tempo real de execuções

## O que Você Vai Aprender

Neste vídeo, você vai aprender:

1. Como criar e gerenciar agentes de IA
2. Como estruturar pipelines com múltiplos passos
3. Como executar pipelines e monitorar em tempo real
4. Como usar placeholders para passar dados entre passos
5. Como configurar entrada e saída de cada passo

## Tecnologias

- **Frontend**: Angular TypeScript
- **Backend**: Java Spring Boot
- **Banco de Dados**: H2 in-memory
- **Comunicação**: REST API + SSE
