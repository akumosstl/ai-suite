# Criando o projeto

- vá para a pagina http://localhost:4200/menu
- clique no menu dropdown "Project"
- Escolha a opção "New Project"
- Preencha o formulário:
- Project Name: "helloworld-copilot"
- Description: "My first Agentic Code project"
- Project Location: "C:\Users\MEUCOMPUTADOR\.agentic-workspace\helloworld_copilot"
*** tire um screenshot aqui ***
- clique no botão: "Create Project"

# Criando uma pipeline

- Na página "/project" clique no botão "Create new pipeline" (sinal de "+")
- Na área "Create New Pipeline" preencha o formulário:
	- Pipeline Name:  HelloWorld
	- Output Extension: json
*** tire um screenshot aqui ***
- Clique no botão: "Save Pipeline"

# Criando o primeiro agent item

- De volta a página "/project" clique no menu superior "Stack" depois no item: "Agents"
- estando na página de "/agents" na área de "Agent Details" preencha o formulário:
	- Name: hello_world_agent
	- Namespace: io.github.akumosstl
	- Path: 
	- Description: Hello World Agent!
	- clique no botão "Edit prompt" no modal window "Edit Agent Prompt" no textarea "Prompt" digite:
		- Just output: Hello {{agentic-input:file}}
		- Clique no botão "Save"
	*** tire um screenshot aqui ***
	- Clique no botão "Create Agent"
- Clique no botão: "Back" no menu superior.

# Adicionando steps na pipeline

- Na página "/project" no painel a esquerda clique para expandir a lista de pipelines ( labeled como: "1 pipeline(s)")
- Clique na pipeline chamada: HelloWorld que vai ser exibida
- Clique no botão "Add Step" (Add step to pipeline)
- No modal "Add Step to Pipeline" na aba "Agents" selecione o agent: "hello_world_agent" na listagem de agents 
*** tire um screenshot aqui ***
- clique no botão "Add to pipeline" e clique ok no alert window dizendo que o agent foi inserido com sucesso a pipeline


 # Configurando o step

- agora a pipeline tem um step clique no botão: "Settings" do step (ícone de engrenagem)
- na aba "Input" digite no campo "Input Content" valor "World!"

# Adicionando script a pipeline

- estando na página de "/agents" na área de "Agent Details" preencha o formulário:
	- Name: hello_world_script
	- Namespace: io.github.akumosstl
	- Path: 
	- Description: Hello World Script!
	- clique no botão "Edit prompt" no modal window "Edit Script Content" no textarea "Prompt" digite:
		- echo {{agentic-output:file}}
		- Clique no botão "Save"
